# Welcome to Psiche Writer

Create or open a book folder to start writing.

- **New book…** makes a new book folder; add chapters with **New chapter…**.
- **Open book…** opens a book folder you already have.

Each chapter is a Markdown file. Write on the left, and the page appears here as it will look in the book.
